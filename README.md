### Como penso os dados

| Etapa | O que procuro garantir | Evidência no portfólio |
| :--- | :--- | :--- |
| **Ingestão** | Origem identificável e contratos de entrada | BCB API, arquivos operacionais e eventos sintéticos |
| **Transformação** | Regras explícitas, validação e normalização | Python, dbt e conciliação de royalties |
| **Modelagem** | Estruturas que facilitam análise e consumo | Dimensões, fatos e marts em DuckDB/dbt |
| **Operação** | Falhas visíveis e recuperação documentada | CI, CloudWatch, DLQ e ensaios de restauração |
| **Entrega** | Dados compreensíveis para quem decide | SQL, dashboards e documentação de negócio |
